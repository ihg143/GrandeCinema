# GrandeCinema
Application web de réservation pour Le Grand Cinéma

Convention de nommage des branches:

main : contient la version stable du projet.

develop : permet d'intégrer les nouvelles fonctionnalités en cours de développement.


## Convention de nommage des branches Git

| Type de branche | Utilisation | Exemple |
|---|---|---|
| `feature/` | Développement d'une nouvelle fonctionnalité | `feature/reserver-places-en-ligne` |
| `fix/` | Correction d'un bug pendant le développement | `fix/correction-pagination` |
| `hotfix/` | Correction urgente d'un bug en production | `hotfix/correction-paiement` |
| `release/` | Préparation d'une nouvelle version | `release/v1.0.0` |

## Convention de nommage des commits

| Type de commit | Utilisation | Exemple |
|---|---|---|
| `feat:` | Ajout d'une nouvelle fonctionnalité | `feat: ajouter API de réservation avec Swagger` |
| `fix:` | Correction d'un bug | `fix: corriger les alertes SonarCloud` |
| `docs:` | Modification de la documentation | `docs: mettre à jour le README` |
| `test:` | Ajout ou modification de tests | `test: ajouter les tests de réservation` |
| `refactor:` | Amélioration du code sans changer son comportement | `refactor: simplifier le contrôleur` |
| `style:` | Modification du formatage du code | `style: corriger l'indentation` |
| `chore:` | Maintenance et configuration du projet | `chore: mettre à jour les dépendances` |
